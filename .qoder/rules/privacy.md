# Privacy (platform-wide)

- **Never commit** student grades, names, IDs, marksheets, or bulk student submissions to git.
- **Never upload** identifiable student data to external services (APIs, cloud tools, chat).
- Process all sensitive data **locally only** — do not upload to external services or paste into chat.
- Use synthetic / anonymised data for examples and tests.
- When in doubt about whether data is sensitive, treat it as sensitive.
