# 優質教育基金（QEF）電子學習撥款計劃（流動電腦裝置及上網支援）

## When to use

- Trigger phrases:
  - 「QEF 電子學習撥款」
  - 「流動電腦裝置 / 借出 iPad / notebook」
  - 「router / SIM / 上網支援」
  - 「10月借用紀錄」
  - 「claim / 財務報告 / 申領發還」
- Situations:
  - 每年 6–7 月開始準備下一學年申請、採購、借用及財務申報

## Purpose (計劃宗旨)

為支援學校在「新常態」下推行混合教學模式，讓公營中小學及直資學校申請撥款，購買流動電腦裝置供有經濟需要學生借用，以及向未能獲得合適上網服務的學生提供可攜式無線網絡路由器及流動數據卡，讓學生享有平等的電子學習機會。（節錄自 QEF 指引頁；詳見 [reference.md](reference.md)）

## Definition of done

- 已在限期內遞交申請（如需要）
- 已在學年內完成採購／付款，並提交所需電子文件申領發還
- 已更新借用紀錄（10 月）並保存資產/借用/數據卡紀錄
- 已在限期內完成財務報告／claim（如適用）

## Workflow (month-by-month checklist)

### 6–7 月：收到 Circular／啟動年度檢視

- [ ] 讀最新通函/指引，更新關鍵日期（申請、採購完成、借用紀錄更新、財務報告）
- [ ] 盤點存量：回收裝置、可再借出的裝置/路由器、仍在用的 SIM/數據卡
- [ ] 建立「受惠名單草稿」及分類（綜援／書簿津貼全/半額／校本識別）
- [ ] 準備家長信（見下方模板），預告借用安排與責任（遺失/損壞、AUP）

### 7 月：出家長信，收集參與意向/資料

- [ ] 發出家長信並設定回覆期限（建議 7–10 日）
- [ ] 收集學生資料與證明（綜援/書簿津貼/校本識別文件、上網需要證明如有）
- [ ] 建立（或更新）「資產記錄表」及「借用紀錄表」欄位（裝置序號、借出/歸還日期、學生、配件、SIM）

### 8 月：採購準備（不建議提早交付）

- [ ] 整理採購清單：裝置 + 3 年保養、MDM（最長 3 年）、基本配件（保護套、鍵盤、筆、耳機等）
- [ ] 如屬「上網支援」：router 及/或 數據卡需要量
- [ ] 比價/招標/採購文件按校內採購規程準備

### 9/1 後（新學年）：落單採購、安排借出

- [ ] 按「先借回收設備 → 不足才申請/購置新設備」原則分配
- [ ] 完成採購後，準備透過「學校通訊模組」提交：
  - [ ] 《購置裝置及受惠學生資料表》
  - [ ] 發票/付款收據副本
  - [ ] 學生資格證明文件副本
- [ ] 借出前完成：
  - [ ] 家長/學生簽收（含 AUP 可接受使用政策）
  - [ ] 設備點收（序號、配件、狀態）

### 10 月：更新「借用紀錄」

- [ ] 按教育局提供的校本 Excel，輸入過往學年購置設備的最新借用情況
- [ ] 確保「回收→再借」記錄完整（畢業/轉校歸還、再分配）

### 11 月後：準備 claim / 財務核實（按通函/學校類別）

- [ ] 整理本學年（例如 9/1–6/30）所有合資格開支憑證
- [ ] 核對是否已於「採購完成限期」前完成所有採購程序並於學年內付款
- [ ] 依規定完成財務報告/核實及保存文件（建議同時備份電子版）

## Key rules (quick reminders)

- **申請截止**：以通函為準（例：2025/26 學年為 2026-01-31）。
- **採購完成**：一般要求於指定 4 月底或之前完成所有採購程序並於學年內付款。
- **資助上限（例）**：基本撥款每名學生上限 4,900；上網支援新合資格上限 800（router+數據卡）；延續受惠學生數據卡上限 450。（以最新通函為準）
- **記錄要求**：獨立資產記錄表 + 借用紀錄 +（如有）數據卡資料；文件需保存多年以備查核。

## Templates

### 家長信（意向 + 借用責任）模板（中文）

```text
主旨：優質教育基金電子學習撥款計劃 — 借用流動電腦裝置／上網支援安排（202_/__學年）

各位家長：

為支援同學進行混合模式學習，本校將安排合資格學生借用流動電腦裝置（及/或 可攜式無線網絡路由器／流動數據卡）作學習用途。

請家長於【日期】或之前回覆是否需要參與，並按需要提交相關證明文件（如綜援/書簿津貼／校本經濟需要證明；及如適用，上網需要相關資料）。

借用須知（摘要）：
1) 借用設備屬學校資產，學生須妥善保管及按「可接受使用政策」使用；
2) 學生畢業／轉校／不再需要借用時，須按通知交還；
3) 如遺失／嚴重損壞，家長及學生須按校方安排處理（維修/賠償安排以校方指引為準）。

如有查詢，請聯絡【負責同事姓名／電話／電郵】。

此致
【學校名稱】
【日期】
```
