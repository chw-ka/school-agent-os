# Subjects

教學區（依科目/級別建立子資料夾，例如 `S3-CMP/`, `S1-Math/`）。

建議每科目結構：
- `question-bank/`：題庫（JSON/Markdown）
- `templates/`：科目專用範本（可選）
- `generated/`：工具輸出（docx/pdf）

## Subjects
Teaching workspace organized by subject/class groups (e.g., `S3-CMP`, `S1-Math`).

Recommended per-subject structure:
- `source/`: raw content (markdown/json/question bank)
- `templates/`: subject-specific templates (optional; prefer global `templates/` when possible)
- `output/`: generated exams/worksheets
