# AI 小裝置嘗鮮課——學生學習單
**小五 STEAM · UIFlow 2.0 · Vibe Coding**

---

## 第一步——連接裝置

1. 用 USB-C 線連接裝置與電腦
2. 裝置畫面顯示雲端圖示 + 數字，例如 `6 / 1269170`
3. 開啟 Chrome → **uiflow2.m5stack.com**
4. 按**連接裝置** → 輸入數字 → **執行一次**
5. ✅ 裝置顯示 UIFlow 標誌 = 連接成功！

> WiFi 已預先設定好——你甚麼都不用做。

---

## 第二步——顯示文字

- 找 **硬件 → 顯示 → Label → 設定文字**
- 拖入 `On Start` → 輸入你的名字 → 按 ▶ **執行**
- 你的名字出現在裝置上！

---

## 第三步——計分器

按下面的方式砌積木：

| 積木 | 功能 |
|------|------|
| 變數 `score = 0` | 建立一個裝置可以記住的數字 |
| `On Start` → 設定 Label = score | 程式開始時顯示分數 |
| `當 BtnA 被按下` → score 加 1 → 設定 Label = score | BtnA 加分 |
| `當 BtnB 被按下` → score 設為 0 → 設定 Label = score | BtnB 重設 |

執行後試試：按 BtnA 加分，按 BtnB 歸零。

## 第五步——用語音告訴 Gemini

1. 開啟 **gemini.google.com**
2. 按麥克風圖示 🎤（語音輸入）
3. 根據你填好的畫面表，描述你的遊戲：

**可以這樣說：**

> *「幫我用 UIFlow 2.0 MicroPython 為 M5StickS3 寫一個考反應遊戲。  
> 畫面一顯示【你填的文字】，按 BtnA 開始。  
> 然後等一個隨機時間，LED 閃【你的顏色】，顯示【你的文字】。  
> 記錄我按 BtnA 的速度，用毫秒顯示。  
> 若在等待時按下，顯示【你的文字】。  
> BtnB 重設遊戲。」*

4. 複製 Gemini 生成的程式碼
5. 在 UIFlow 2.0 → 切換至 **Python 模式**（右上角）
6. 貼上 → ▶ **執行** → 在裝置上測試！

---

## 遇到問題？
- 程式出現錯誤 → 將錯誤訊息貼給 Gemini，說「請幫我修復這個錯誤」
- 按鈕沒有反應 → 告訴 Gemini：「M5StickS3 的按鈕名稱是 BtnA、BtnB、BtnPWR」
- 畫面沒有顯示 → 檢查程式碼中有沒有建立 label 元件
