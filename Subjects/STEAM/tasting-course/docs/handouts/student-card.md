## 第一步——連接裝置

| 步驟 | 你做甚麼 | 成功時會見到 |
|------|---------|-------------|
| 1 | 用 USB-C 線連接裝置與電腦 | 裝置有畫面 |
| 2 | 看裝置畫面 | 雲端圖示 + 數字（例：6 / 1269170） |
| 3 | Chrome 開啟 **uiflow2.m5stack.com** | 網頁打開 |
| 4 | 按 **連接裝置** → 輸入數字 → **執行一次** | 裝置顯示 UIFlow 標誌 ✅ |

| 小提示 |
|--------|
| WiFi 老師已設定好，你甚麼都不用做。 |

---

## 第二步——顯示你的名字

| 步驟 | 你做甚麼 |
|------|---------|
| 1 | 找 **硬件 → 顯示 → Label → 設定文字** |
| 2 | 拖入 **On Start** 積木 |
| 3 | 輸入你的名字 |
| 4 | 按 ▶ **執行** |

| 成功時 |
|--------|
| 你的名字出現在裝置上！ |

---

## 第三步——砌計分器

跟老師一起砌積木：

| 用甚麼積木 | 做甚麼 |
|-----------|--------|
| 變數 | `score = 0`（分數由 0 開始） |
| **On Start** | 設定 Label = score（一開始顯示 0） |
| **當 BtnA 被按下** | score 加 1 → 更新 Label |
| **當 BtnB 被按下** | score 變回 0 → 更新 Label |

| 試試 | 應該會… |
|------|--------|
| 按 BtnA | 分數上升 |
| 按 BtnB | 分數變回 0 |

---

## 第四步——設計你的考反應遊戲

**⚠️ 先填好下面表格，才去用 Gemini！**

遊戲有 **5 個畫面**。在空格寫下**你的版本**：

| # | 畫面 | 裝置顯示甚麼？（填寫） | 你要做甚麼？ |
|---|------|----------------------|-------------|
| 1 | **開始** | ＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿ | 按 **BtnA** 開始 |
| 2 | **等待** | ＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿ | 不要按！等 1.5–3.5 秒 |
| 3 | **GO！** | ＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿ | 快按 **BtnA**！ |
| 3 | **GO！** | LED 閃甚麼顏色？＿＿＿＿＿＿＿＿ | （同上） |
| 4 | **結果** | 顯示 ＿＿＿＿＿ 毫秒 | 按 ＿＿＿ 再玩一次 |
| 5 | **太早了** | ＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿ | 按 ＿＿＿ 再試一次 |

| 例子（你可以照抄或改） |
|----------------------|
| 開始 → 「按 A 開始！」｜等待 → 「準備好…」｜GO！ → 「NOW！按 A！」+ 紅色 LED｜結果 → 「XXX 毫秒 👍」｜太早了 → 「太早了！」 |

## 第五步——用語音告訴 Gemini

| 步驟 | 你做甚麼 |
|------|---------|
| 1 | 開啟 **gemini.google.com** |
| 2 | 按 🎤 麥克風（用說話輸入） |
| 3 | 照你填的表格，描述你的遊戲（見下表） |
| 4 | 複製 Gemini 給你的程式碼 |
| 5 | UIFlow 2.0 → 右上角切 **Python 模式** |
| 6 | 貼上 → ▶ **執行** → 在裝置上試玩！ |

**可以這樣說（把【】改成你填的內容）：**

| 你要講 | 內容 |
|--------|------|
| 開頭 | 幫我用 UIFlow 2.0 MicroPython 為 M5StickS3 寫一個考反應遊戲 |
| 畫面一 | 顯示【你填的文字】，按 BtnA 開始 |
| 等待 + GO | 等隨機時間，LED 閃【你的顏色】，顯示【你填的文字】 |
| 計時 | 記錄我按 BtnA 有多快，用毫秒顯示 |
| 太早按 | 等待時若按下，顯示【你填的文字】 |
| 重設 | BtnB 重設遊戲 |

## 遇到問題？

| 問題 | 你可以這樣做 |
|------|-------------|
| 程式有錯誤 | 把錯誤訊息貼給 Gemini，說：「請幫我修復這個錯誤」 |
| 按鈕沒反應 | 告訴 Gemini：「按鈕名稱是 BtnA、BtnB、BtnPWR」 |
| 畫面空白 | 告訴 Gemini：「請加入 label 顯示文字」 |
