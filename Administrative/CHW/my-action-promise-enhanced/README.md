## 「我的行動承諾」加強版撥款計劃

本資料夾對應優質教育基金（QEF）「我的行動承諾」加強版撥款計劃。

### 計劃概要

| 項目 | 詳情 |
|------|------|
| **全名** | 「我的行動承諾」加強版撥款計劃 |
| **資助來源** | 優質教育基金（QEF） |
| **最高撥款** | 中小學（含特殊學校）：每校 **30 萬元**；幼稚園：15 萬元 |
| **資助範疇** | 國民教育、國家安全教育、媒體及資訊素養教育 |
| **申請截止** | 加強版：至 **2026-08-31**；第二階段：**2025-09-01 至 2028-08-31** |
| **注意** | 加強版與第二階段撥款**不可同期進行** |

### 第二階段（加強版第二階段）

| 項目 | 詳情 |
|------|------|
| **新增範疇** | 在上述三個範疇外，擴闊至**促進學生身心健康** |
| **申請期** | 2025-09-01 至 2028-08-31 |

### 可資助活動

- 學生講座 / 工作坊
- 參觀體驗活動
- 教師工作坊
- 購買或製作教材
- 家長講座 / 工作坊
- 體驗活動
