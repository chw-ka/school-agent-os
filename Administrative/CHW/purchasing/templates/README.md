## How to Use These Templates

1. **For Reference Only:** These files are for understanding form structure and requirements.

2. **Get Latest Versions:** Before filling out actual forms:
   - Go to `S:\01_School Administration\11_Useful Forms\Finance`
   - Check for updated versions (year-specific forms)
   - Use the most recent version

3. **Fill Out Carefully:**
   - Use clear, specific descriptions
   - Double-check amounts and calculations
   - Ensure all required signatures are obtained

4. **Follow Approval Chain:**
   - Don't skip any approval levels
   - Allow sufficient time for each reviewer
   - Keep copies of approved forms

5. **Submit Properly:**
   - After purchase, submit original receipt + approved form copy to school accountant
   - Retain your own copies for 3-year record keeping

---

## Annual Updates

These forms may be updated annually. Check for new versions at the start of each school year (September).

**Typical update cycle:**
- August: School reviews and updates forms for new academic year
- September: New forms become effective
- Old forms may still be valid for ongoing procurements started under previous year
