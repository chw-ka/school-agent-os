# 2. 檢查：下學期比重與滿分

**目的**：在同事大量入分之前，確認各級各科的**計分比重**與**滿分**設定正確。此步驟的查詢結果常會**匯出 Excel 或列印**，交科目主任、級組、教務核對。

## 主要資料表

| 用途 | 資料表 | 下學期相關欄位 |
|------|--------|----------------|
| 各科比重 | `tblFormPaperWeight` | `weight_test_2`、`weight_regular_2`、`weight_exam_2` |
| 各科滿分 | `tblFormPaperScore` | `score_test_2`、`score_regular_2`、`score_exam_2` |
| 學年兩期權重（學年總分用） | `tblFormTermWeight` | `weight_1`、`weight_2` |

**規則**：有計分的科目，下學期三項比重加總應為 **0**（不計）或 **100**。

## 執行檢查 SQL

開啟並在 SSMS 執行（可先只跑前幾段 SELECT）：

```
../sql/03 Check Report Data/Check Record Entries (term 2).sql
```

或舊備份：

```
T:\25-26\ITAdmin_13_StudentReport/_Program/SQL Scripts/03 Check Report Data/Check Record Entries (term 2).sql
```

腳本內容包括（節錄）：

1. 比重加總不等於 0 或 100 的 `(form, idPaper)`
2. 有比重但滿分為 0 或 NULL
3. 應有分卻為 0／NULL 的學生（按任教老師列出）
4. 體育／音樂等以等級顯示的缺漏
5. 分數超過滿分
6. 缺態度、操行與紀律矛盾等（**PED 功課考勤唔使入**；見 `3_入分` 態度例外表）

腳本內 `form in (1,2,3,4,5)` 及 `flgTerm2 = 1` 已針對中一至中五下學期。

## 計分方法（各科總成績點計）

步驟 2 只負責**比重與滿分設定**；真正把入分變成成績表上嘅分數，係步驟 **5** 跑 `../sql/04 Make Summaries/Calculate Score_special_edition.sql`（或教務指定嘅其他年份版本），結果寫入 **`tblZStudentRank2`**，步驟 6 出表時讀 **`section = 'O'`** 作為該科**下學期總分**。

### 資料對應（下學期 term = 2）

| 設定（步驟 2） | 入分（步驟 3） | 計分腳本用嘅檢視欄位 |
|----------------|----------------|----------------------|
| `weight_test_2`、`weight_regular_2`、`weight_exam_2` | — | `vwFormPaperWeight` → `weightTest`、`weightRegular`、`weightExam` |
| `score_test_2`、`score_regular_2`、`score_exam_2` | — | `vwFormPaperScore` → `scoreTest`、`scoreRegular`、`scoreExam` |
| — | `score_test_2`、`score_regular_2`、`score_exam_2` | `vwStudentPaperScore` → `scoreTest`、`scoreRegular`、`scoreExam` |

有計分嘅卷／科：`weight_test_2 + weight_regular_2 + weight_exam_2` 應為 **0**（唔計）或 **100**。

### 內部儲存與成績表顯示

- `tblZStudentRank2.score` 為**整數**，成績表上顯示嘅百分制分數 ≈ **`score ÷ 10`**（例：庫內 `785` → 表上 `78` 或 `78.5`，視欄位格式；總分欄多用整數，平均欄或有小數）。
- 低於 **`score < 495`**（即 &lt; 49.5 分）會以**括號**顯示（見 `Report.sql`）。
- 腳本註明：**所有運算按一位小數處理**；中間步驟常用 `floor(…/10 + .5)*10` 做四捨五入到 0.1 再繼續計。

### 計分分段（`tblZStudentRank2.section`）

| section | 含義 | 下學期來源 |
|---------|------|------------|
| `R` | 測驗＋平時（非考試部分） | 由 `score_test_2`、`score_regular_2` 計 |
| `E` | 考試 | 由 `score_exam_2` 計（複合科另有合併，見下） |
| `O` | **該科總分** | 由 `R` 與 `E` 按三項比重加權 |
| `term = 0` | 學年 | 上、下學期 `O` 按 `tblFormTermWeight.weight_1`、`weight_2` 加權 |

成績表 Word 合併大致對應：`result_1` ← `R`，`result_2` ← `E`，`result_final` ← **`O`（總分）**。

### 1. 平時／測驗分（section `R`）

只計**有設定比重**嘅項；每項先換算成「滿分百份比」再加權：

```
R_內部 = floor(
  ( w_test   × score_test_2   / score_test_2滿分   [有測驗比重且有分時]
  + w_regular × score_regular_2 / score_regular_2滿分 [有平時比重且有分時]
  ) ÷ (w_test + w_regular)
)
```

- `w_*` = `weight_test_2`、`weight_regular_2`；滿分來自 `tblFormPaperScore`。
- 某一項無分或滿分為 NULL，該項當 **0** 計入分子（唔會計入有比重但缺分嘅項，除非兩邊都有值）。

### 2. 考試分（section `E`）

**一般卷（`idSubject = idPaper`）** — 以 **`Calculate Score_special_edition.sql`** 為準（含調分曲線）：

設 `P = 100 × score_exam_2 ÷ score_exam_2滿分`（百分率 0–100），`@tuningFactor` 預設 **7.45**（腳本頂部可改，改前須與教務確認）：

```
若 P < tuningFactor²（約 55.5）：
  E_內部 = floor( sqrt(P) × tuningFactor × 100 )
否則：
  E_內部 = floor( 10000 × w_exam × score_exam_2 / 滿分 ÷ w_exam )
         = floor( 100 × score_exam_2 / 滿分 × 100 )   -- 與 w_exam 約簡後
```

即：**低分段用 √(百分率)×7.45 拉高**；**高分段用線性百分×100 儲存**。舊版 `_Calculate Score 2021.sql` **無**此平方根，考試全程線性 `10000×…`。

**複合科（`idSubject ≠ idPaper`，例如中、英分卷）**：先對每卷算出 `E`，再按 `tblFormPaperWeight.weight` 加權平均到**科目**層的 `idPaper = idSubject`。

### 3. 該科總分（section `O`）— 成績表上嘅「總成績」

先把 `R`、`E` 各四捨五入到 0.1（`floor(score/10+0.5)*10`），再按**三項比重**加權：

```
O_內部 = floor(
  ( round₁(R) × (w_test + w_regular) + round₁(E) × w_exam )
  ÷ ( (w_test + w_regular) [若 R 有計] + w_exam [若 E 有計] )
)
```

- 只有平時無考試、或只有考試無平時嘅科，分母只含**有比重嘅部分**（與腳本 `CASE WHEN weight… > 0` 一致）。
- 顯示總分 ≈ **`O_內部 ÷ 10`**。

### 4. 學年總分（`term = 0`）

各科（及平均列）用上、下學期已計好嘅 `R`／`E`／`O`，按 **`tblFormTermWeight`** 的 `weight_1`、`weight_2` 加權；只有一個學期有分時，學年分 = 該學期分。

### 5. 全級平均、標準分、名次

- **全級平均**（`idPaper = ''`）：各科的 `O`（或 `R`／`E`）按 `tblFormPaperWeight.weight`（科目權重）加權平均。
- **標準分**（`flgStandard = 1`）：`(score/10 − 該科該 section 平均) ÷ 標準差`。
- **班、級名次**：在 `O` 等 section 上按 `score` 排序寫入 `rankClass`、`rankForm`。

### 與步驟 2 的關係（核對時要知）

| 步驟 2 檢查 | 影響計分的方式 |
|-------------|----------------|
| 三項比重和 ≠ 0 且 ≠ 100 | `O` 加權錯誤或 SQL 篩選不到該科 |
| 有比重但滿分為 0／NULL | 該項當無法換算，分子為 0 |
| 入分超過滿分 | 可算出 &gt;100 的百分率（檢查腳本會列出） |
