# 總覽：中一至中五下學期成績表流程

本資料夾內各步驟指引以數字前綴排序。**數字小並不代表一定要等上一步 100% 完成**；見下方「可同步進行」一節。有依賴關係的步驟仍須按先後做。

| 檔名 | 步驟 |
|------|------|
| `1_準備_確認下學期修讀與學期旗標.md` | 確認誰要出表、修讀哪些科 |
| `2_檢查_下學期比重與滿分.md` | 核對計分比重與滿分（常匯出／列印俾同事） |
| `3_入分_同事輸入與資料表.md` | 各科分數、態度、操行、評語等入庫 |
| `4_可選_評估分轉測驗分.md` | 若使用評估系統自動寫入測驗分 |
| `5_計分_排名與學年彙總.md` | 計算 `tblZStudentRank2` |
| `6_生成_成績表快照.md` | 產生 `tblZStudentReport2` |
| `7_匯出_列印核對稿與改名.md` | Word 合併列印 PDF、`_rename.bat` |
| `8_核對_特殊個案與修訂.md` | 特殊學生、同事回饋、手動修訂 |
| `9_可選_寫入學生檔案庫.md` | 定稿後寫入年度 `tblY*` |
| `10_行政分工_下學期時序與聯絡.md` | **行政 Workflow**：幾時問 ES／PY／班主任、升留班前後分工 |
| `11_遲缺與考試缺席_Excel轉SQL.md` | PY／PC Excel → `tblStudentDiscipline`／考試缺席 SQL |

**中六**流程另見：`6S_中六下學期成績表重新生成指引.md`

## 可同步進行（並行）一覽

圖例：**可同步**＝兩邊可同時做｜**部分可同步**＝只有某一部分可先做｜**不可**＝必須等前步完成

### 準備階段（入分前）

| 可與誰同步 | 步驟 | 說明 |
|------------|------|------|
| **可同步** | **1** ↔ **2（前半）** | **1** 改退學／修讀旗標的同時，**2** 可先跑「各科比重加總是否 0 或 100」「有比重但滿分是否漏設」——呢啲只查 `tblFormPaperWeight`、`tblFormPaperScore`，唔依賴個別學生名單。比重／滿分清單亦可提早匯出俾同事簽核。 |
| **部分可同步** | **1** ↔ **2（後半）** | **2** 入面「邊個學生缺分、缺態度」等檢查，要等 **1** 退學生 `flgTerm2 = 0`、修讀科目搞掂先跑，否則會誤報退學生缺分。 |
| **可同步** | **1、2** ↔ **行政準備** | 撰寫 `Datafile/.../SpecialCases.txt` 草稿、準備 Word 範本路徑、今次 `Copies` 資料夾命名、通知各科組入分時間表——唔阻塞 SQL。 |
| **不可** | **3** 入分 | 必須等 **2** 比重／滿分獲教務確認後先大規模入分（避免改比重後全部重入）。 |

**答你嘅問題**：**第一步同第二步可以同步進行**，尤其係 **2 的比重與滿分檢查**；退學生處理（**1**）同 **2 的學生缺分檢查** 就要分工清楚——旗標未改好前唔好當缺分錯誤。

### 入分與計分階段

| 可與誰同步 | 步驟 | 說明 |
|------------|------|------|
| **可同步（人事上）** | **3** 各科入分 | 不同科目老師可同時入分、入態度（同一資料庫，注意唔好改同一學生同一科）。 |
| **部分可同步** | **3** ↔ **4** | 若用評估系統寫 `score_test_2`，評估匯入（**4**）可與老師入平時／考試分（**3**）交錯進行；兩者都依賴 **1** 修讀名單。 |
| **不可** | **5** 計分 | 要等 **3** 完成（及 **4** 如適用）；入分未完成計排名會錯。 |
| **可同步** | **5** 各 form | `form = 1…5` 可連續執行或分開時段做，彼此獨立（同一 DB 逐個 form 跑較穩陣）。 |

### 出表與核對階段

| 可與誰同步 | 步驟 | 說明 |
|------------|------|------|
| **不可** | **6** 生成快照 | 必須等 **5** 完成。 |
| **可同步** | **6** 各 form | `stpGenerateReport 1,2` … `5,2` 可一次過排隊執行。 |
| **不可** | **7** 列印 PDF | 必須等 **6** 完成（或至少該 form 已生成）。 |
| **可同步** | **7** 各 form | 各級 Word 合併、出 PDF、跑 `_rename.bat` 可分人做不同 form。 |
| **部分可同步** | **7** ↔ **8** | 同事睇 PDF 核對稿同時，IT 可依已知名單準備 **8** 的 SQL；**新發現** 要改分數仍須回 **3→5→6→7**。 |
| **不可** | **9** 檔案庫 | 必須等 **8** 定稿、不再改快照。 |

### 建議時間線（簡圖）

```
[1 學期旗標／退學] ──┬── [2a 比重滿分檢查] ──► 教務確認 ──► [3 入分] ──► [5 計分] ──► [6 快照] ──► [7 PDF]
                     │         ▲
                     └── [2b 學生缺分檢查] ── 要等 1 完成
                              （入分後再跑 2 全份）

平行行政：SpecialCases 草稿、Word 範本、通告資料夾
平行（可選）：[4 評估分] 與 [3] 交錯
平行：核對稿簽核 [7] 與 已知特殊個案 SQL 準備 [8]
```

### 必須順序執行嘅骨幹（不可跳）

```
1（學生名單）→ 2 確認比重滿分 → 3 入分 → 5 計分 → 6 快照 → 7 列印
                                    ↘ 4（可選，與 3 交錯）
7／8 定稿後 → 9（可選）
```

## 資料流（簡要）

```
學生／科目設定 (flgTerm2)
  → 比重／滿分 (tblFormPaperWeight / tblFormPaperScore)
  → 入分 (tblStudentPaperScore 等)
  → 計分排名 (tblZStudentRank2)
  → 成績表快照 (tblZStudentReport2)
  → Word 合併 → PDF 核對稿
```
