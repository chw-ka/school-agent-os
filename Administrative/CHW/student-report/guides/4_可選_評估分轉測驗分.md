# 4.（可選）評估分轉測驗分

**目的**：若學校使用 `tblAssessment2` 等評估模組，可透過 stored procedure 將評估結果匯總後寫入 `tblStudentPaperScore.score_test_2`（下學期）。

**若你校今年無使用評估入分，可跳過本步，直接進行步驟 5。**

## 相關腳本

```
../sql/02 Retrieve Assessment Results/Calculate Assessment.sql
```

## 程序

- **`stpCalculateAssessment @form, @term`**
  - 下學期：`@term = 2`
  - 中一至中五：對 `form = 1` 至 `5` 分別執行

## 程序會做的事（摘要）

1. 補齊缺少的 `tblFormPaperScore`、`tblStudentPaperScore` 列
2. 將 `vwStudentAssessment2` 的 credit 換算為 0–100 分，更新 `score_test_2`
3. 將相關 `tblAssessment2.flgCompleted` 設為已完成

## 注意

- 技術備忘曾記錄：部分環境 `tblStudentAssessment2` 可能無資料，則本步不會產生效果。
- 執行前請確認 `tblFormTerm` 下學期日期範圍與評估 `dateFrom` 對應正確。

## 完成後

進行 **`5_計分_排名與學年彙總.md`**。
