# 6. 生成：成績表快照

**目的**：將分散在多表的成績、態度、操行、評語、服務、獎項等，**扁平化**寫入 **`tblZStudentReport2`**，供 Word 郵件合併列印成績表核對稿。

## 重要概念

`tblZStudentReport2` 是**快照表**。之後若只改 `tblStudentAttitude`、`tblStudentPaperScore` 等來源表，**不會自動更新**報表內容，必須重新執行本步。

## 相關腳本

定義與執行 `stpGenerateReport`：

```
../sql/06 Make Reports/_Report_2023_S123.sql
```

或：

```
../sql/06 Make Reports/Report.sql
```

（以你校當年指定版本為準；舊備份在 `T:\.../06 Make Reports/`。）

## 執行（中一至中五、下學期）

在 SSMS 對當年度資料庫執行：

```sql
EXEC dbo.stpGenerateReport 1, 2;
EXEC dbo.stpGenerateReport 2, 2;
EXEC dbo.stpGenerateReport 3, 2;
EXEC dbo.stpGenerateReport 4, 2;
EXEC dbo.stpGenerateReport 5, 2;
```

參數：`(@form, @term)`，`@term = 2` 為下學期。

程序會先 `DELETE` 該 form、該 term 的舊列，再重新 INSERT／UPDATE 各欄位（科目行最多約 27 行、平均、名次等）。

## 驗證（建議）

```sql
SELECT term, form, COUNT(*) AS 人數
FROM tblZStudentReport2
WHERE form BETWEEN 1 AND 5 AND term = 2
GROUP BY term, form;

-- 抽查一名學生
SELECT Class, Num, CName, ave3, CRank3, FRank3
FROM tblZStudentReport2
WHERE form = 2 AND term = 2 AND Class = '2A' AND Num = '01';
```
