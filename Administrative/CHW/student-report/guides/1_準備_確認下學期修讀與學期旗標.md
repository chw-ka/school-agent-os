# 1. 準備：確認下學期修讀與學期旗標

**目的**：確保「下學期要計分、要出成績表」的學生與科目名單正確，否則後續入分、計分、出表會漏人、漏科。

## 要檢查的欄位

| 層級 | 資料表／檢視 | 下學期旗標 |
|------|----------------|------------|
| 學生 | `tblStudent` / `vwStudent` | `flgTerm2 = 1` 表示該生下學期仍屬在讀、可出表 |
| 修讀科目 | `tblStudentSubject` / `vwStudentSubject` | `flgTerm2 = 1` 表示該生下學期修讀該科 |

出報表程序 `stpGenerateReport` 只會納入同時滿足「該 form、該學期有修讀科目」的學生。

## 開學初應一併確認

- 轉班、新插班生是否已更新 `tblStudent.class`
- 選修、分組（`tblStudentSubject.auxiliaryClass`）是否正確  
  - **中/英/數分組碼對照表**：[`../reference/CEM_GROUPING_EXCEL_TO_AUXILIARY_CLASS.md`](../reference/CEM_GROUPING_EXCEL_TO_AUXILIARY_CLASS.md)（中一、四、五、六；Excel 組別 ↔ `1U`/`4W`/`5V`…）  
  - 選修 X1/X2/X3、選修課堂分組：查 DB 或校內分組 Excel（見 [`../reference/CEM_GROUPING_EXCEL_TO_AUXILIARY_CLASS.md`](../reference/CEM_GROUPING_EXCEL_TO_AUXILIARY_CLASS.md)）
- 新開科目是否已在 `tblStudentSubject` 建立，且 `flgTerm2` 已設

## 建議查詢（只讀檢查）

```sql
-- 例：中一是否有學生 flgTerm2 未開
SELECT form, COUNT(*) AS 人數
FROM vwStudent
WHERE form BETWEEN 1 AND 5
GROUP BY form;

-- 例：某級缺 flgTerm2 的修讀科目
SELECT ss.form, ss.idSubject, COUNT(*) AS 筆數
FROM vwStudentSubject ss
WHERE ss.form = 1 AND ss.flgTerm2 = 0
GROUP BY ss.form, ss.idSubject;
```

（實際條件請按你校當年規則調整。）
