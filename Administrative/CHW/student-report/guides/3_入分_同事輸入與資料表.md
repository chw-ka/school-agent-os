### NULL 與 0 點入？（教務 CM 慣例，2026-06-26）

同事入分時常問「留空定打 0」。**原則如下**（CM 卓文）：

#### 分數（`score_test_2`／`score_regular_2`／`score_exam_2`）

| 情況 | 入咩 | 備註 |
|------|------|------|
| **豁免** | `NULL`（配合 `flgIgnore_2 = 1`） | 成績表顯示「豁免」 |
| **缺席** | `NULL`（配合 `flgAbsent_2 = 1`） | 成績表顯示「缺席」 |
| **其餘所有情況**（包括真係攞 0 分） | **`0`** | **唔好用 NULL 代替零分** |
| 成績表上顯示 | **一定要有數字 0–100** | 豁免／缺席用旗標，唔係用「空」混亂同事 |

一句話：**只有豁免、缺席先 NULL；其他一律 0。**

#### 態度（`lesson_2` 上課表現、`assessment_2` 功課考勤）

| 情況 | 入咩 |
|------|------|
| **比唔到評級**（例如長缺、未見過學生） | **`NULL`** |
| 可以評級 | A／B／C／D 等（照平時做法） |

例：長缺學生從未上課 → **上課表現留 NULL**，唔好硬填字母。

#### IT 檢查腳本注意

`Check Record Entries (term 2).sql` 同 `B_ZeroMarkChecking.xlsx` 會把 **`NULL` 同 `0` 都當「缺分」** 列出，方便追漏項；**唔代表**同事應該一律留空。追數時要分：

- 真係未入 → 應改為 **0** 或實際分數  
- 豁免／缺席 → 應設 **`flgIgnore_2`／`flgAbsent_2`**，分數欄可 NULL  
- 態度比唔到 → 維持 NULL（長缺等）

## 入分後品質檢查

**必須再執行一次**：

```
../sql/03 Check Report Data/Check Record Entries (term 2).sql
```

重點查看：

- 缺分、超分
- 已標豁免／缺席卻仍有分數
- 缺態度（**PED／MUS／PBL 唔查功課考勤 `assessment_2`**；PED 仍要查上課表現 `lesson_2`）
- 操行與遲缺、功課記錄是否矛盾
