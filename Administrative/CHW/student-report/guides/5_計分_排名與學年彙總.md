# 5. 計分：排名與學年彙總

**目的**：由原始分數、比重、滿分計算出標準化分數、各科總分、平均、班名次、級名次，寫入 **`tblZStudentRank2`**。成績表生成（步驟 6）依賴此表。

## 執行前

1. 確認步驟 2、3 已完成
2. 確認使用**當學年實際採用**的計分腳本（不同年份檔名可能不同）

## 常用腳本位置

```
../sql/04 Make Summaries/Calculate Score_special_edition.sql
```

其他版本（僅在教務指定時使用）：

- `Calculate Score 2013.sql`
- `_Calculate Score 2021.sql`

舊備份：`T:\25-26\.../04 Make Summaries/` 下同路徑。

## 執行方式

1. 開啟腳本，在頂部設定變數（若腳本使用變數）：
   - `@term = 2`（下學期）
   - `@form = 1` … `5`（逐級執行，或按腳本內 `stpCalculateScore_*` 呼叫）
2. 部分版本含 **`@tuningFactor`**（考試分調整），修改前須與教務確認
3. 對 form 1–5 各執行一次完整計分

腳本通常會：

- `DELETE` 該 form 在 `term in (0, @term)` 的舊 `tblZStudentRank2` 記錄
- 插入 section：`R`（平時）、`E`（考試）、`O`（總分）等
- 計算平均（`idPaper = ''`）及 `rankClass`、`rankForm`

## 驗證（建議）

```sql
-- 例：中二下學期是否有排名資料
SELECT COUNT(*) FROM tblZStudentRank2 WHERE form = 2 AND term = 2;

-- 抽查一名學生
SELECT * FROM tblZStudentRank2
WHERE idStudent = <某idStudent> AND form = 2 AND term = 2
ORDER BY idPaper, section;
```
