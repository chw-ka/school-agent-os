# 8. 核對：特殊個案與修訂

**目的**：處理不發核對稿、豁免、清走部分欄位、分卷缺席顯示、獎項文字等**非一般計分**情況；整合同事回饋後確保 PDF 與最終發放版本正確。

## 特殊個案記錄位置

按學年、學期存放文字清單，例如：

```
T:\25-26\ITAdmin_13_StudentReport/Datafile/25_26_Term1/D_SpecialCases.txt
T:\24-25\ITAdmin_13_StudentReport/Datafile/24_25_Term2/24_25_SpecialCases.txt
```

內容可能包括：不獲發核對稿、豁免考試、清走總分／名次／態度欄等。

中六科獎、獎學金等人選另見：

```
T:\25-26\.../S6_ReportProcessing/SpecialCases_科獎_其他獎項.txt
```

## 修訂原則

| 情況 | 建議做法 |
|------|----------|
| 源頭資料錯（分數、態度） | 改 `tblStudentPaperScore`、`tblStudentAttitude` 等 → **重做步驟 5、6** |
| 只改報表顯示（快照已生成） | 可 `UPDATE tblZStudentReport2`，但易與源頭不一致；**優先重做步驟 6** |
| 報表腳本內建特殊 UPDATE | 執行 `Report_S6_special_edition.sql` 等檔內**未註解**的段落；勿跑已註解的舊案例 |

## 中六注意（與 S1–S5 類似）

若已清空 `tblStudentAttitude` 但 Word 仍顯示舊態度，代表 **`tblZStudentReport_S456` 快照未重生**，須執行 `stpGenerateReport_S456_2014 6, 2`，不能只改來源表。詳見 **`6S_中六下學期成績表重新生成指引.md`**。

## 同事回饋修訂

舊資料夾常有「同事核對後修訂」記錄，例如：

```
T:\25-26\.../Datafile/25_26_Term1/同事核對後修訂/
```

修訂落實後：

1. 更新資料庫
2. 必要時重做 **5 → 6 → 7**
3. 重新列印受影響學生或全班 PDF

## 編碼提醒

執行含**中文常數**的 `UPDATE` 時，請用 T 碟或原始 Big5／Unicode 正確的 `.sql` 檔。若複製後中文變 `???`，勿用該檔更新，以免寫壞資料。

## 完成後

- 定稿 → 可選 **`9_可選_寫入學生檔案庫.md`**
- 正式發放、通告附件等按校內行政流程（`Copies/.../出通告/` 等資料夾）
