# 9.（可選）寫入學生檔案庫

**目的**：成績表定稿並發放後，將本期計算結果與相關資料**歸檔**至年度 `tblY*` 表，供往後查閱、獎學金抽取、統計分析等。

**警告**：此類腳本會 **INSERT／UPDATE** 歷年表，執行前請確認學年、學期，並已備份。

## 相關腳本

下學期：

```
../sql/07 Portfolio/Update Student Portfolio 2nd term.sql
```

上學期（對照）：

```
../sql/07 Portfolio/Update Student Portfolio 1st term.sql
```

中六下學期：

```
../sql/07 Portfolio/S6_Update Student Portfolio 2nd term.sql
```

舊備份：`T:\25-26\.../07 Portfolio/` 下同檔名。

## 歸檔內容（摘要）

技術備忘記載的對應關係包括：

| 來源 | 歸檔目標（示例） |
|------|------------------|
| `tblZStudentRank2` 彙總 | `tblYStudentScore` |
| `tblStudentConduct` | `tblYStudentConduct` |
| `tblStudentComment` | `tblYStudentComment` |
| `tblStudentDiscipline` | `tblYStudentDiscipline` |
| `vwStudentPaper` 等 | `tblYStudentPaperTerm`、`tblYStudentPaperScore` 等 |

詳見 `../reference/STUDENT_REPORT_SQL_TABLE_RELATIONSHIPS.md` 的 Portfolio 章節。

## 執行時機

- 在 **步驟 8** 完成、成績表不再改動之後
- 通常每學期一次
