
## 3. 兩道「開關」（缺一不可）

同事要見到入分畫面並儲存，須同時滿足：

### A. 資料庫：`tblFormInputControl`（入分時段開關）

每個 **`(form, term)`** 一列，控制該級該學期可入咩、是否已開放：

| 欄位 | 含義 |
|------|------|
| `flgTest` / `flgRegular` / `flgExam` | 是否容許入測驗／平時／考試分 |
| `flgConduct` | 是否容許入操行 |
| **`flgActiveSubject`** | **1 = 任教老師可入分、態度**（最重要） |
| **`flgActiveClass`** | **1 = 班主任可入操行、評語** |
| `flgActiveAssessment` | 評估系統 `aflNet` 用 |

程式邏輯（[`studentNet/report/Default.aspx.vb`](../../../old_intranet/studentNet/report/Default.aspx.vb)）：

- 一般老師：`flgActiveSubject = 1` 先見到科目／班別清單。
- **`Student Record Administrators`**（`admin:1` on `/studentNet/report/`）可繞過開關代入。

主選單是否顯示「成績表 → 輸入」：[`studentNet/Default.aspx.vb`](../../../old_intranet/studentNet/Default.aspx.vb) 的 `isReportInputOpened()` 同樣查 `tblFormInputControl` + 任教／操行安排。

### B. 帳號：`tblUser` + `tblUserControl`（邊個可以入 SchoolNet）

| idUserGroup | 名稱 | 典型路徑 | 用途 |
|-------------|------|----------|------|
| **7** | **Score Input Users** | `/studentNet/`、`/studentNet/report/` | **一般教職員入分**（全校約百多人） |
| **6** | Student Record Administrators | `/studentNet/`、`/studentNet/report/` + **`admin:1`** | 教務／IT 代入、管理 |
| 各級 S1–S5 Teachers | （多個群組） | `/studentNet/ecac/` + `ecac:register` 等 | 按級 ECAC 登記／列印 |

**`adminNet` 唔會**直接改 `tblFormInputControl`；Account 頁管理的是 **用戶群組與路徑**（`tblUserGroup`、`tblUser`、`tblUserControl`）。

開學年文件會暫時 **`UPDATE tblUserGroup SET flgActive = 0 WHERE idUserGroup IN (..., 7, ...)`**，入分前要確認 **群組 7 已重新啟用**（`flgActive = 1`）。

## 4. 開放下學期入分：建議步驟（term = 2，中一至中五）

### 4.1 前置（應已完成）

- [ ] 步驟 1：`flgTerm2`、修讀科目正確  
- [ ] 步驟 2：比重、滿分已確認  
- [ ] `tblStaffSubject`、`tblStaffClass` 已反映今學年任教（Excel／SQL generator，見年度流程文件）  
- [ ] 教職員帳號在 `tblUser`（群組 **7** 或 **6**）

### 4.2 檢查 `tblFormInputControl`

**預覽腳本（建議直接用）**：

```
../sql/03 Check Report Data/Open Term2 Score Input (preview).sql
```

內含 §一 只讀預覽、§二 寫入 UPDATE（主鍵只得 `form`，改 `term=2` 開開關）。

```sql
SELECT form, term, flgTest, flgRegular, flgExam, flgConduct,
       flgActiveSubject, flgActiveClass, flgActiveAssessment
FROM dbo.tblFormInputControl
ORDER BY term, form;
```

- 應有 **`form = 1…5` 各一行**；`term` 欄表示**而家開緊邊個學期**（主鍵只得 `form`，唔係每學期一行）。
- 開放下學期：**UPDATE `term = 2`** 並設 **`flgActiveSubject = 1`、`flgActiveClass = 1`**（唔好 INSERT 新列，會違反 PK）。

```sql
UPDATE dbo.tblFormInputControl
SET term = 2,
    flgActiveSubject = 1,
    flgActiveClass   = 1
WHERE form BETWEEN 1 AND 5;
```

### 4.3 同時關閉中六下學期入分（必做）

`tblFormInputControl` **每級只得一行**。程式 **冇** hardcode「只限 form 1–5」；中六會唔會出現，睇 **form = 6 嗰行** 嘅設定。

開 S1–S5 下學期時，**form 6 保持 `term = 2` 亦可**，但要關開關：

```sql
UPDATE dbo.tblFormInputControl
SET flgActiveSubject = 0,
    flgActiveClass   = 0,
    flgActiveAssessment = 0
WHERE form = 6;
```

**一般任教老師**（群組 7）：form 6 `flgActiveSubject = 0` 就 **唔會** 見中六下學期入分 grid。

**教務 admin 帳**（`/studentNet/report/` 有 `admin:1`）：程式用 `(@flgAdmin = 1 OR fic.flgActiveSubject = 1)`，**仍可能** 喺下拉揀中六老師並入分——即使 form 6 已關 active。測試時請用**普通任教帳**，或 admin 勿揀 S6 老師。

中六另階段再開：form 6 `flgActiveSubject/Class = 1`（`term` 通常已是 2），見 `6S_中六下學期成績表重新生成指引.md`。

### 4.4 確認用戶群組已啟用

```sql
SELECT idUserGroup, nameChinese, flgActive
FROM dbo.tblUserGroup
WHERE idUserGroup IN (6, 7);

-- 若 Score Input Users 被關閉：
-- UPDATE dbo.tblUserGroup SET flgActive = 1 WHERE idUserGroup = 7;
```

新同事若入唔到站：喺 **`adminNet → Account`** 將帳號加入 **Score Input Users**，或複製 **User Template (Staff)**（年度流程文件有 `insert tblUser select 64, idUser from tblUserInfo ...` 類似做法）。

### 4.5 設定學期日期（可選）

年度文件會更新 `tblFormTerm` 的 `dateStart`／`dateEnd`（下學期例：`term = 2`）。與入分限期通告一致即可。

### 4.6 驗證

1. 用**一般任教帳號**（非 admin）登入 → `/SchoolNet/studentNet/` 應見 **成績表 → 輸入**。  
2. 入 `/SchoolNet/studentNet/report/default.aspx` → 應見自己任教班／科。  
3. 用 **Student Record Administrators** 帳號 → 可揀其他老師代入（頂部 staff 下拉）。  
4. 跑 [`Check Record Entries (term 2).sql`](../sql/03%20Check%20Report%20Data/Check%20Record%20Entries%20(term%202).sql) 監察缺分（入分開放後）。

### 4.7 截止入分

```sql
UPDATE dbo.tblFormInputControl
SET flgActiveSubject = 0,
    flgActiveClass   = 0
WHERE term = 2 AND form BETWEEN 1 AND 5;
```

之後進行步驟 5 計分（見 [`5_計分_排名與學年彙總.md`](./5_計分_排名與學年彙總.md)）。

## 5. adminNet 帳號管理（IT）

路徑：**`/SchoolNet/adminNet/Account.aspx`**（需本身有 admin 權限登入）。

| 功能 | 做咩 |
|------|------|
| **User group** | 揀群組 → 下方顯示該組可去的 **path**（`tblUserControl`） |
| **User** | 群組內成員（`tblUser`） |
| **Add / Edit user group** | 新增路徑，例如 `/studentNet/report/`、參數 `admin:1` |

常見路徑（摘自資料庫）：

- `/studentNet/` — 進入學生紀錄  
- `/studentNet/report/` — 成績表入分  
- `/studentNet/report/` + `admin:1` — 教務管理員  
- `/studentNet/ecac/` — ECAC 入職位  
- `/activityNet/` + `admin:1` — 編輯全校活動  

**`adminNet/Execute.aspx`**：批次執行 SQL／XML 請求（高權限），**唔係**日常開放入分介面；開 `tblFormInputControl` 用 SSMS 或核准腳本較常見。

其他 adminNet 頁：重設密碼、Substitute、Clear cache、更新教師 profile 等，與入分開放無直接關係。

## 7. 疑難排解

| 現象 | 可能原因 | 處理 |
|------|----------|------|
| 成績表「輸入」連結唔見 | `flgActiveSubject`／`flgActiveClass` 皆 0；或無任教 | 查 §4.3；查 `vwStaffSubject` |
| 入到 studentNet 但 report 空白 | 群組 7 無 `/studentNet/report/`；或無任教 | Account 加路徑；查 `tblStaffSubject` |
| 淨係教務入到 | 群組 6 `admin:1` 正常；一般老師未開 Active | 開 `flgActiveSubject`；確認群組 7 `flgActive=1` |
| 某科唔見 | 比重為 0；或 `flgTerm2=0`；或複合科卷別條件 | 步驟 2 比重；步驟 1 旗標 |
| ECAC 唔見 | 無 `/studentNet/` 或 ecac 參數 | 查 `tblUserControl`；S1–S5 教師群組 |
| 改完 DB 仍舊 | IIS／快取 | `adminNet/ClearCache.aspx`；或重載 AppPool |

缺分清單（開放前內部用）：`/SchoolNet/studentNet/report/NoInputReport.aspx`（在 `flgActiveSubject = 0` 時列出應入未入）。
