# 6S. 中六下學期成績表重新生成指引

日期備忘：2026-05-15（內容整理自原 `S6_REPORT_REGENERATION_GUIDE_20260515.md`）

## 用途

說明如何重新產生中六（form 6）下學期成績表的 **Word 郵件合併資料**。若只改來源表（如 `tblStudentAttitude`）而唔跑重生，合併出嚟嘅 PDF 仍會係舊快照。

## 關鍵檔案

| 類型 | 路徑（校內 T 碟示例） |
|------|------------------------|
| Word 主檔 | `T:\25-26\ITAdmin_13_StudentReport\_Program\Copies\2026_03_24_S6_成績表核對稿\MasterCopies\25_26_S6ReportDraft.doc` |
| 主 SQL（含特殊個案） | `...\SQL Scripts\06 Make Reports\Report_S6_special_edition.sql` |
| 程序定義來源 | `...\SQL Scripts\06 Make Reports\_Report_2014_S456.sql` |
| 本 repo 精簡 SQL | `export/6S_中六郵件合併_2526下學期.sql` |

## 郵件合併資料表

```sql
dbo.tblZStudentReport_S456
```

此表為**生成快照**，唔會因來源表改動而自動更新。

## 重要發現（案例：6C02）

- 學生：6C02 蔡凱玥，`idStudent = 20061`
- `tblStudentAttitude` 已清空 `lesson_2`、`assessment_2`
- 但 `tblZStudentReport_S456` 的 `Lsn_*`、`Asm_*` 仍為舊值  

**原因**：報表快照在清空態度之前已生成。

## 點解重生可修正

`stpGenerateReport_S456_2014 6, 2` 會：

```sql
DELETE FROM tblZStudentReport_S456
WHERE form = @form AND term = @term;
```

再從 `tblStudentAttitude` 等重算 `Lsn_*`、`Asm_*`。當來源為 `NULL` 時，程序寫入空字串，唔再顯示上課表現／功課考勤文字。

## 建議執行範圍

開啟 `Report_S6_special_edition.sql`，**只執行**由：

```sql
-- Sub Program Call
stpGenerateReport_S456_2014 6, 2
Go
```

至檔內現行 **6D15（idStudent 20078）** 特殊個案 `UPDATE` 結束為止。

**勿執行**其後已註解的舊特殊案例（如「分卷全數缺席時考試分轉缺席」等 CHI 段落）。

## 唔好只跑底部 UPDATE

檔尾 `UPDATE tblZStudentReport_S456 ...` 只處理個別個案，**唔會**由 `tblStudentAttitude` 重建態度欄。關鍵係：

```sql
stpGenerateReport_S456_2014 6, 2
```

## 重生後檢查

```sql
SELECT *
FROM dbo.tblZStudentReport_S456
WHERE form = 6 AND term = 2
ORDER BY Class, Num;

SELECT Class, Num, CName,
       Lsn_01, Asm_01, Lsn_07, Asm_07, Lsn_16, Asm_16, Lsn_18, Asm_18
FROM dbo.tblZStudentReport_S456
WHERE form = 6 AND term = 2 AND idStudent = 20061;
```

6C02 預期：相關 `Lsn_*`、`Asm_*` 為空白。

## 現行特殊個案（執行時一併處理）

`idStudent = 20078`（6D15）：清空總分、平均、班級／級名次及部分態度顯示等（見 `Report_S6_special_edition.sql`）。

6C02 **唔在**此 UPDATE 名單內，應靠重生從已清空的 `tblStudentAttitude` 帶出空白。

## 編碼警告

含中文常數的 `UPDATE` 請用 **T 碟原始 SQL 檔** 執行。複製後若中文變 `???`，可能寫壞比對條件，勿使用。
