# 7. 匯出：列印核對稿與改名

**目的**：由 `tblZStudentReport2` 經 **Word 郵件合併** 產生 PDF 成績表核對稿，交班主任、科目老師、級組簽核；再用批次檔將 PDF 改為「班別＋班號」檔名。

## 中一至中五

### 資料來源

- 資料表：**`dbo.tblZStudentReport2`**
- 條件：`form` = 1–5，`term` = 2（下學期）

### Word 主檔位置（不在本 repo 內）

主檔通常在校內共用磁碟，路徑結構與 `old/` 備份類似，例如：

```
T:\25-26\ITAdmin_13_StudentReport\_Program\Copies\2026_02_06_成績表核對稿_S1245\
  MasterCopies\          ← 各級 Word 範本
  S1_ReportDraft_出通告\
  ...
```

檔名模式示例：`25_26_Term2_S1ReportDraft.doc`（實際以當年資料夾為準）。

### 操作概要

1. 開啟對應年級 Word 範本
2. 郵件合併 → 連線 SQL Server → 選 `tblZStudentReport2`（或已匯出的查詢／連結表）
3. 篩選 `form`、`term`
4. 合併至新文件 → **匯出 PDF**（常見檔名：`...ReportDraft-001.pdf`、`-002.pdf` …）

### PDF 改名

合併後執行該次核對稿資料夾內的 **`_rename.bat`**，將序號改為班號，例如：

```
24_25_Term2_S1ReportDraft-001.pdf  →  24_25_Term2_S1ReportDraft_1A01.pdf
```

本 repo 備份範例：

```
T:\24-25\.../Copies/2025_06_26_S12345_成績表核對稿/_rename.bat
T:\25-26\.../Copies/2026_02_06_成績表核對稿_S1245/_rename.bat
```

第一版核對稿包括：成績與態度、ECA／服務、優點缺點、考勤、操行評語、獎項名次；**唔包括**升留班備註。詳見 **`10_行政分工_下學期時序與聯絡.md`**「第一版核對稿包括咩」一節。
