# shared-tools

存放通用的 Python 技能腳本（Skills / Shared Tools）。

原則：
- 工具優先（Tool First）
- 輸入輸出明確（JSON/檔案路徑）
- 可重現、可測試、可重用

## shared-tools
Reusable Python tools ("Shared Tools") for school automation.

- Goal: make execution tasks deterministic and repeatable (formatting, filling templates, processing data).
- All tools should accept structured input (JSON/YAML) and produce artifacts (DOCX/PDF/CSV) in a consistent, school-standard format.
